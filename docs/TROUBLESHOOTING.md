# Troubleshooting

## ESP32 does not appear

1. Unplug USB.
2. Plug it back in.
3. Try another data cable.
4. Check the COM port.
5. Install the correct USB-to-serial driver if needed.

## Upload fails

Check the board, COM port, USB cable, and whether your board needs a BOOT-button procedure.

## Wi-Fi fails

Check the Wi-Fi name, password, router access, and distance from the router.

## No sound

Do not change random pins. Identify your ESP32 model, microphone, amplifier or speaker, and XiaoZhi hardware configuration first.

## Bot hears nothing

Check microphone wiring and audio configuration.

## Bot hears you but does not answer

Check Wi-Fi, XiaoZhi server or endpoint settings, device registration, and speaker wiring.

## MCP does not work

Test the MCP server separately first, then connect the ESP32.
